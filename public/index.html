macOS balances active RAM, compression, and SSD swap automatically.

WiredPinned

Memory pinned in RAM — macOS can never page it out, compress, or swap it (kernel, GPU, display & audio buffers, ML/AI compute).

Freeing it: cannot be purged — the kernel's share clears on a reboot, app locks clear when the app quits.

CompressedPacked in RAM

Your apps' own unused memory, packed. When an app's pages sit idle, macOS compresses them in RAM instead of writing SSD swap.

Freeing it: quit idle apps or close tabs — compression alone isn't slow, macOS unpacks pages on demand.

File cacheReclaimable

Disk data cached for instant reads. macOS reclaims it automatically the moment any app needs RAM — a big cache is healthy.
